# أدوات تنظيف الملفات ونقر الفأرة التلقائي

يتضمن هذا المستودع سكربتين مكتوبتين بلغة بايثون:

1. **cleanup.py**: يقوم بحذف الملفات المؤرشفة (مثل: `.zip`, `.rar`, `.tar`, ...) والملفات المؤقتة (مثل: `.tmp`, `.temp`, `.swp`، ...).
2. **autoclicker.py**: برنامج للنقر التلقائي للفأرة مع إمكانية التحكم بسرعة وعدد النقرات.

## المتطلبات

- Python 3.8 أو أحدث
- مكتبة [pyautogui](https://pypi.org/project/pyautogui/) لتشغيل `autoclicker.py`
  - تثبيت: `pip install pyautogui`

## طريقة التشغيل

### تنظيف الملفات المؤرشفة والمؤقتة

```bash
python cleanup.py /path/to/dir
```

- استبدل `/path/to/dir` بالمجلد الذي تريد تنظيفه (الافتراضي هو المجلد الحالي).
- استخدم الخيار `--dry-run` لعرض الملفات فقط بدون حذفها.

### النقر التلقائي للفأرة

```bash
python autoclicker.py --interval 0.2 --button left --count 100
```

- `--interval`: المدة بالثواني بين كل نقرة (الافتراضي 0.1 ثانية).
- `--button`: زر الفأرة (`left`, `right`, `middle`).
- `--count`: عدد النقرات المطلوب تنفيذها (0 يعني الاستمرار حتى الإيقاف يدويًا).

لإيقاف النقر التلقائي، اضغط `Ctrl+C` أو حرّك مؤشر الفأرة إلى الزاوية العلوية اليسرى للشاشة (ميزة Fail-Safe الخاصة بـ`pyautogui`).
